Описание структуры проекта:
src/db/__main__.py - запуск программы
src/db/tui.py - консольный интерфейс, тут меню, ввод команд и вывод информации
src/db/backend/memory.py - основная логика базы данных, тут хранение записей и работа с ними
src/db/backend/errors.py - свои ошибки для программы
tests/test_memory.py - тесты для проверки программы

Функциональность программы:
добавление записей
просмотр всех записей
поиск записей по полям
обновление записей
удаление записей
обработка ошибок

Запуск программы:
терминал (в корневой папке проекта):
python -m src.db

тестов:
python -m unittest
