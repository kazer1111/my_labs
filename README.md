Описание структуры проекта:
- `src/db/__main__.py` - точка входа в программу
- `src/db/tui.py` - консольный интерфейс, реализованный через класс `StudentTUI`
- `src/db/backend/memory.py` - база данных, реализованная через класс `StudentTable`
- `src/db/backend/errors.py` - пользовательские исключения
- `tests/test_memory.py` - тесты для базы данных и интерфейса

Функционал:
- добавление записей
- просмотр всех записей
- поиск записей по полям
- обновление записей
- удаление записей
- обработка ошибок
- использование классов для базы данных и интерфейса

Запуск:
- в корневой папке выполнить `python -m src.db`
- для запуска тестов выполнить `python -m unittest`
