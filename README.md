## Описание структуры проекта:

- `src/db/__main__.py` - точка входа
- `src/db/tui.py` - консольный интерфейс (ввод команд + вывод информации)
- `src/db/backend/memory.py` - наша база данных (добавление удаление записей + в допе обновление и поиск)
- `src/db/__init__.py` - файл для backend

## Функционал:

добавление, удаление записей, просмотр всех записей, поиск записей по полям, обновление записей, обработка ошибок и удаление записей.

## Запуск:

(в корневой папке) в терминал:

```powershell
python -m src.db
```
