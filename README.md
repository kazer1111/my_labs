Описание структуры проекта:
src/db/__main__.py : запуск программы
src/db/tui.py : консольный интерфейс, тут выбор типа базы данных, меню, ввод команд и вывод информации
src/db/backend/database.py : общий интерфейс для работы с базой студентов
src/db/backend/memory.py : in-memory реализация, данные хранятся только во время работы программы
src/db/backend/file.py : файловая реализация в формате JSON
src/db/backend/csv_file.py : файловая реализация в формате CSV
src/db/backend/errors.py : свои ошибки для программы
tests/test_memory.py : тесты для in-memory реализации
tests/test_file_database.py : тесты для JSON реализации
tests/test_csv_database.py : тесты для CSV реализации
tests/test_tui.py : тесты для интерфейса

Различия между реализациями:
In-memory база хранит записи только в памяти и после завершения программы данные пропадают.
JSON база хранит записи в json файле, поэтому данные остаются на диске.
CSV база хранит записи в csv файле, поэтому данные тоже сохраняются после завершения программы.

Функциональность программы:
добавление записей
просмотр всех записей
поиск записей по полям
обновление записей
удаление записей
обработка ошибок
выбор типа базы данных при запуске

Запуск программы:
терминал в корневой папке проекта:
python -m src.db

Проверка программы:
python -m unittest
